# 線上預約流程 v2（規格草案，2026-10-06 討論定案）

取代原本「教練手動批次開放時段 → 學生申請 → 核准即完成」的流程。開放時段改由
「每週可教時間」配合教練紀錄工具（coaching-record-tool，以下簡稱教練工具）的
行事曆自動算出，並加上付款、退費與防濫用規則。

## 1. 學生看到的流程

```
選課程 → 選地區（新北／新竹）→ 選日期 → 選時段 → 填資料＋勾選同意退費規則 → 送出
```

- 可預約範圍：**開課日 ≥ 今天 + 7 天**（日曆日計算，與當下幾點無關），且 ≤ 今天 + 8 週。
- 7 天內的日期不開放，顯示「7 天內的課程請直接私訊教練」＋ LINE 官方帳號（待提供）。
- 時段旁標示場館；緊接在教練同館既有課程前後的時段標「⭐ 推薦」並排在前面。
- 送出前顯示費用明細（教練費＋場地費）與退費規則，必須勾選「已閱讀並同意」，
  系統記錄同意時間。
- 頁面提醒「送出申請不代表預約成功，教練確認後會以 Email 通知付款」。

## 2. 預約狀態

```
pending 待審核
  ├─ 教練拒絕 ──────────────────────────→ rejected 已拒絕
  ├─ 開課前 5 天仍未審核（系統自動）─────→ rejected（通知學生改私訊）
  └─ 教練核准（可調整金額）
       ▼
awaiting_payment 待付款（核准起 24 小時）
  ├─ 24 小時內未回報匯款（系統自動）──→ expired 逾期取消，時段釋放
  └─ 學生回報匯款（匯款時間＋帳號後五碼；匯款時間須在核准後、截止前）
       ▼
payment_reported 待對帳（時段持續保留）
  ├─ 教練確認收款 ──────────────────────→ confirmed 預約完成 ✅
  └─ 教練標記未收到款項 ────────────────→ cancelled（通知學生）

confirmed
  └─ 學生申請取消 → cancel_requested（顯示適用退費級距、通知教練）
       └─ 教練退款後按「完成取消」──────→ cancelled

expired／cancelled 在時段仍空著時，教練可按「恢復預約」（學生其實有在期限內匯款
但忘了回報、私訊教練後的補救）。
```

- **付款期限以學生回報的匯款時間為準**，教練晚對帳不影響學生。
- 核准時在教練工具建立課程（付款狀態「未付款」），讓行事曆保持正確、24 小時內
  不會被其他課撞到；逾期／取消時自動把那堂課改成「已取消」（教練工具視為時段
  釋放）；教練確認收款時自動標記那堂課已付款，教練不用兩邊各按一次。
- 改期 = 取消後重新預約，或私訊處理，不另做改期功能。
- 線上預約只做單堂課；套組（固定時段多週）與多人上課走私訊，多人可在備註寫人數、
  教練核准時調整金額。

## 3. 費用與退費

- **教練費**：取預約網站該課程設定的價格（後台「課程」的參考價改名為教練費）。
- **場地費**：依教練工具新增的「場館 × 時段價目表」，以上課的場館、星期、時段
  計算（見 §5）。
- 總額 = 教練費 + 場地費；教練核准時可手動調整兩者（熟客、多人）。
- 建立到教練工具的課程：`revenue_amount` = 教練費、`venue_fee_amount` = 場地費
  （不再用教練工具價目規則推算，確保跟學生看到的金額一致）。

退費規則（預約頁、確認信、常見問題都顯示）：

| 申請取消時距離上課 | 退費 |
|---|---|
| 7 天以上 | 全額退費，扣除轉帳手續費 |
| 4～7 天 | 只退教練費，場地費不退 |
| 4 天內 | 教練費、場地費都不退 |

退款由教練自行轉帳，系統只負責算出適用級距與記錄狀態。

## 4. 開放時段怎麼算

- 教練在預約網站後台設定「每週可教時間」規則：星期幾、開始～結束時間、地區、
  該地區可用的場館（場館清單從教練工具讀取，名稱保證一致）。
- 學生選了地區＋日期後，預約網站把當天符合的規則送給教練工具的新整合端點，
  由教練工具用「找空檔」同一套判斷（不撞課、算車程、工作時段 08:00–22:30、
  整點開始）回傳可約時段，並標出同館接課。
- 再扣掉預約網站自己「已核准但還沒寫進教練工具」的時段（理論上不會有，保險用）。
- 原本的手動開放時段保留為「臨時加開」，與規則算出的時段合併顯示。
- 送出申請時即時再查一次；核准時教練工具建立課程本身也會檢查衝突。
- 教練工具連不上時，預約頁顯示「暫時無法查詢時段」，不會亂開時段。
- 教練工具只回傳可約時間，不帶任何學生或課程內容。

## 5. 教練工具要新增的

- **場館 × 時段價目表**（場地管理頁）：場館、適用星期（可複選）、開始～結束時間、
  每小時場地費。一堂課跨兩個價格時段時按分鐘比例計算；查不到價格時回報錯誤，
  不猜預設值。
- 整合端點（Bearer Token，沿用 `public_booking_api_token`，全部只回必要資訊）：
  - 場館清單（名稱、地區）
  - 可約時段查詢（輸入日期、時段範圍、場館、時長；輸出可約開始時間＋是否同館接課）
  - 場地費試算（場館、日期、開始時間、時長）
  - 建立課程：可帶入教練費、場地費
  - 取消課程（只能取消由預約網站建立的課）
  - 標記已付款（同上）

## 6. 防濫用

時段只有在教練核准後才會被佔用，核准後 24 小時沒付款會自動釋放，所以大量申請
最多只會讓審核清單變長、佔不到行事曆。另外：

1. 每個帳號「尚未上課」的預約（pending＋awaiting_payment＋payment_reported＋
   confirmed）合計最多 **2 小時**，超過提示「要預約更多請私訊教練」。
2. 註冊需驗證 Email 才能送出預約（需要寄信信箱）。
3. 註冊頁加 Cloudflare Turnstile 機器人驗證。
4. 同一 IP 的註冊／登入／送出申請限制頻率（例如每小時 10 次），也擋暴力猜密碼。
5. 累計 2 次核准後未付款逾期 → 停用線上預約，只能私訊。
6. 後台可手動封鎖帳號。

## 7. 通知

| 事件 | 學生 | 教練 |
|---|---|---|
| 送出申請 | Email：已收到 | Discord |
| 核准 | Email：金額、匯款帳號、截止時間 | — |
| 自動拒絕／教練拒絕 | Email | Discord（自動拒絕時） |
| 回報匯款 | — | Discord |
| 確認收款 | Email：預約完成、上課資訊 | — |
| 逾期取消 | Email | Discord |
| 申請取消 | Email：適用退費級距 | Discord |

- 匯款帳號沿用教練工具的 `bank_info.txt` 內容（不進版控），只出現在核准信與
  「我的預約」中該筆待付款的預約。
- 寄件信箱：另開 Gmail＋應用程式密碼（**待提供**）。

## 8. 其他

- 時間一律台灣時間：雲端容器是 UTC，程式內「現在／今天」一律用
  `app/timeutil.py` 的 `now_taipei()`／`today_taipei()`，不用 `datetime.now()`／
  `date.today()`（教練工具 2026-09-29 已經這樣修過，預約網站於批次 0 比照）。
- 既有資料表要加欄位（例如 booking_requests 的金額、狀態、匯款資訊），需要加入
  簡單的資料庫遷移機制，雲端資料庫才能升級而不用刪掉重建。

## 9. 分批實作順序

| 批次 | 內容 | 可否先上線 |
|---|---|---|
| 0 | 預約網站改用台灣時間（教練工具已修過）＋資料庫升級機制 ✅ | 可，獨立修正 |
| 1 | 教練工具：場地價目表（含頁面）＋ 6 個整合端點 | 可，不影響現有功能 |
| 2 | 預約網站後端：每週可教時間、新狀態流程、費用計算、2 小時上限、自動逾期／自動拒絕排程、取消與退費級距、封鎖、頻率限制 | 先不開放給學生 |
| 3 | 預約網站前端：五步驟預約頁、我的預約（回報匯款、申請取消）、後台（規則、核准調金額、對帳、恢復）、刪除課程 | 先不開放給學生 |
| 4 | Email：驗證信＋各種通知、Turnstile | 需要寄件信箱 |
| 5 | 切換上線：關閉舊流程、補上 LINE 官方帳號與退費規則文字 | 需要 LINE 官方帳號 |

**正式對學生開放要等 4、5 完成**：沒有 Email 通知，學生不知道要在 24 小時內付款。
